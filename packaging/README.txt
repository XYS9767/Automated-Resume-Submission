BOSS 自动投递 Windows 便携版

1. 将整个 ZIP 解压到可写目录，保留 EXE、config.yaml 和 BAT 文件在同一目录。
2. 电脑需要 Microsoft Edge，不需要安装 Python。
3. 双击“检查环境.bat”检查配置；双击“预览岗位.bat”只筛选，不打招呼。
4. 双击“启动.bat”正式运行，在专用 Edge 窗口登录自己的 BOSS 账号。
5. 在线简历用于匹配适配度；搜索城市、关键词和薪资使用 config.yaml。
6. 默认深圳、运维/DevOps、岗位起薪15-20K、匹配分至少75，每日程序上限150。
   起薪不足15K、面议和无法确认月薪的岗位会跳过；15-25K、20-30K可以匹配。
   实际网站额度以账号为准；符合条件的岗位不足时会提前结束。
7. 发布版使用通用招呼语。可在 config.yaml 的 submit.greeting 中填写自己的介绍。
8. 运行中保持终端和专用 Edge 打开，电脑不要休眠；验证码需本人完成。
9. 双击“停止自动投递.bat”停止，当前操作结束后保存进度；再次启动可续跑。

“投递成功”表示网站确认发起沟通，不表示发送了本地简历附件。
AI Key 留空时使用本地匹配规则，不需要填写 Key 才能运行。

一个运行目录对应一个账号。更换账号时另解压一份，避免混用去重和计数记录。
运行后的 browser_data、cookies.json、简历、日志和投递记录包含个人信息，请勿上传仓库或转发。
发布包本身不包含任何账号、Cookie、个人简历或历史投递记录。
